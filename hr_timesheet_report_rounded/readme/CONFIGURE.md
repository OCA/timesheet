This module has no settings. It is installed on its own when **Task Logs Timesheet Report** and **Sale Timesheet Rounded** are both installed.

Rounding is set on the project. Only timesheet lines created after the change are rounded.

**Set rounding on a project**

1. Open the **Project** app.
2. Open **Projects**.
3. Open a project.
4. Open the **Settings** tab.
5. Under **Time rounding**, set **Rounding method**.
6. When **Rounding method** is not **No rounding**, set **Rounding Unit**.
7. Set **Timesheet rounding factor in percentage**.
