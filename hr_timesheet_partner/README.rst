This module provides UX improvements to handle partner data in
timesheets:

- Show the partner column in the timesheet list views.
- Allow to quick search by partner in the search bar.

**Table of contents**

.. contents::
   :local:

Usage
=====

To work with partners in timesheets:

1. Go to *Timesheets > Timesheets*.
2. Use the *Partner* column in the timesheet list to review or edit the
   partner linked to each entry.
3. Use the search bar to search timesheet entries by partner.
