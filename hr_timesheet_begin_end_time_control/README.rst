Glue between ``hr_timesheet_begin_end`` and
``hr_timesheet_time_control``.

The timer of ``hr_timesheet_time_control`` records a start and end time
(``Start Time`` / ``End Time``), while ``hr_timesheet_begin_end`` adds
its own ``Begin Hour`` / ``End Hour``. Without this module the two never
meet: a stopped timer leaves Begin Hour and End Hour empty.

This module keeps them in sync:

- Stopping a timer (Stop button, or starting a new timer which stops the
  running one) fills Begin Hour and End Hour in the employee's time
  zone.
- Changing the Start Time or the duration of such a line moves Begin
  Hour and End Hour along.
- Changing Begin Hour moves the Start Time to that hour on the line's
  date.

Lines that cannot be expressed as a begin/end hour on one day (a timer
running past midnight) or whose hours would overlap another line of the
same employee keep empty begin/end hours, so stopping the timer never
fails.

Usage
=====

1. Start a timer on a project or task (**Start work**).
2. Stop it. The timesheet line now shows the **Begin Hour** and **End
   Hour** of the timer, next to the duration.
3. Correcting the Begin Hour or End Hour afterwards also corrects the
   timer's Start Time and End Time.

Known issues / Roadmap
======================

- A line crossing midnight keeps empty begin/end hours;
  ``hr_timesheet_begin_end`` only supports begin and end on the same
  day.
- Time between begin and end that is not worked moves the end hour: the
  end hour is start + duration + ``_get_begin_end_unworked_hours()``.
  The break of ``hr_timesheet_begin_end_break`` is supported out of the
  box; other modules can extend the method.
