This module adds start/stop work buttons on leads/opportunities to
control timesheet timers, gluing together CRM Timesheet and HR Timesheet
Time Control.

When stopping a timer started from a lead/opportunity, a wizard asks for
the work description.

**Table of contents**

.. contents::
   :local:

Usage
=====

- In pipeline/lead form, kanban and list views you have *Start work* /
  *Stop work* buttons to control the running timesheet timer.
- When stopping a timer started from a lead/opportunity, a wizard asks
  you to describe the work done.
