Portal users with access to a project see its timesheets: the timesheet list of the
portal, the timesheets and time spent of each task, the task timesheet report and, with
sales, the timesheets of their orders and invoices. This module adds a per-project option
to hide them. When it is unchecked, the portal and the project sharing views show neither
the timesheet lines of the project nor the allocated time, time spent, time remaining and
progress of its tasks. The option is checked by default, so the portal keeps showing
timesheets until it is unchecked.
