Record the timesheet as usual.
Select a time type on the line.
The analytic amount of the line follows the cost of the time type:

- a ratio of 1.5 on an employee hourly cost of 75.00 gives 112.50 per hour;
- a fixed cost of 31.00 gives 31.00 per hour.

A change in the cost of a time type affects new lines only.
To change the cost of an existing line, set its time type again.
