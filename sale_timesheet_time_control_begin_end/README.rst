This module extends the portal timesheet view provided by
``sale_timesheet`` to properly support begin and end time information in
grouped views.

It adjusts the table layout (colspan values) in the portal template to
ensure correct rendering when begin/end times are displayed.

**Table of contents**

.. contents::
   :local:

Usage
=====

Install this module to enable proper display of begin/end times in the
customer portal timesheet view when using sale timesheet integration.

No further configuration is required after installation.
