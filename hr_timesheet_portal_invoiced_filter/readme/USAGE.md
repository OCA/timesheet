After installation, configure the timesheet visibility in Settings → Timesheets → Timesheet Portal Visibility.
You can choose whether customers see only invoiced timesheets or all timesheets in the portal.

This setting can be overridden per customer on the partner form. If set to "Company default"
(the default value on installation), the company configuration is used as fallback.

The module applies the configured rules to the portal timesheet view and controls the visibility of the
“Amount Due” section on tasks based on the selected mode and whether uninvoiced timesheets exist.
